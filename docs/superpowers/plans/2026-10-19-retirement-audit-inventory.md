Preserve survey-management API fields/order/privacy. Decide whether full lifecycle history also moves to canonical history; scheduler state must remain authoritative locally.

Route each listed writer through it; preserve notification/business outboxes, rollback behavior, and import savepoints. Directory-admin audit reads need an explicitly approved payload visibility contract before any widening or silent field loss.
3. Separate operator/control-plane audit from tenant business history. Export and reconcile both with scoped manifests; archive raw restricted legacy records separately if full retention is required. Do not claim the existing transformed legacy export preserves raw audit history.
