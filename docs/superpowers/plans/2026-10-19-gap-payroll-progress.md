# Durable organization payroll jobs progress

## Contract and ownership

Task B owns Payroll source adapter/worker/state, source migration0119 and the private tenant job refresh helper. Root owns protocol operations, central immutable intent refresh route, shared transport integration and migration master includes. Same-company Payroll resolvers and unrelated loan work are preserved.

Draft/finalize acceptance creates a source job whose ID is the original command ID in the same transaction as the immutable acceptance receipt. The receipt remains `ACCEPTED`; job state separately progresses `QUEUED`, `RUNNING`, `SUCCEEDED`, `FAILED` or `CANCELLED`. Replays return the same acceptance. No bearer/delegation token is persisted.

Job list/detail/cancel require a current explicit companywide payroll grant and the exact original actor, company, organization, membership and grant reference/version. Cancellation is available while queued, before claim. Version checks protect a claim/cancel race.

The source worker claims a five minute random lease using `FOR UPDATE SKIP LOCKED`. Expired claims recover after restart; a stale token cannot finish a newer claim. The execution transaction holds its job row, source membership/grant/account/actor and existing payroll input locks. It obtains a newly signed exact original command delegation from the private central route, verifies signature/body/nonce/current policy and original authority epochs, and loads current entitlements. Existing draft/finalization validation, fingerprints and acknowledgements execute inside that transaction. Business changes and terminal job state commit together. The final update checks the lease and a deferred source constraint rechecks the original running lease at actual commit, closing the timing gap between those statements. Expired leases roll back the business transaction. Confirmed denied authority/domain conflicts fail closed; transport/database outages retry with a bounded attempt count.
